# 财富自由临界值计算器

按「永续提款」口径估算财富自由所需资产：不工作、按当前开支生活，本金不缩水、购买力不下降。

计算方法取自 B 站「小Lin说」的相关视频：<https://www.bilibili.com/video/BV1yUHP6rEYD/>

本仓库只是把它做成了可直接使用的计算器，并未改变其核心逻辑；参考数据另做了核对与补充（见下方「参考值来源」）。**建议先看原视频再使用本工具**，口径的来龙去脉在视频里讲得更完整。

单文件静态页面（`FFC.html`），零依赖，离线可用。打开 `FFC.html` 即可。

## 怎么用

所有输入默认是 `0`，从你要算的那一项开始填：

1. **必填**：每月生活开支 `X`、实际回报率 `r`（点 chip 选 2.5% / 4% 即可）
2. **选填**：孩子数 `N`、单孩成本 `K`、健康 `M`、住房 `H`、现有资产 `A`，用不上就留 0
3. 填够就实时出结果，没填够时右侧只显示一句提示，不会给出误导性的 0

底部的参考值 chip 可以直接点，把全国/城镇/北上广深的数据填进去。

## 公式

```
临界值 = (12 ÷ 实际回报率) × 月生活开支 X
       + 单孩育儿成本 K × 孩子数 N
       + 终身健康预留 M
       + 住房投入 H
```

乘数由实际回报率（已扣通胀）决定：

| 实际回报率 | 乘数 | 口径 |
|---|---|---|
| 2.5% | 480 倍 | 永续，本金不动 |
| 4.0% | 300 倍 | 4% 法则，30 年耗尽 |
| 8.0% | 150 倍 | — |

480 倍比 4% 法则严 60%，因为前者要求本金永续、后者允许 30 年后花光。

## 口径提醒（最容易算错的地方）

- **X 不含房贷**。房贷有到期日，不是永续支出；填进 X 会把 480 倍乘数放大 30 年。
- **X 若填「人均消费支出」这类总额**（已含居住、医疗、育儿），则 K、M、H 必须清零，否则重复计算。城市数据还要按家庭人口放大（三口之家约 ×2.5）。
- **K、M、H 是固定额，不进乘数**。它们是一次性/阶段性支出，不需要永续现金流支撑。

## 参考值来源

- **人均消费支出**（X 的 chips）：2025 年各地统计公报。深圳 53,548 元/年、上海 54,765、北京 50,667、广州 49,177，÷ 12 得月额。全国 2,456、城镇 2,990 为国家统计局口径。
- **育儿成本**（K 的 chips）：全国 58 万、城镇 66.7 万取自《中国生育成本报告》；一线与成都按该报告同一算法（分段人均消费支出 + 教育加成）测算，支出基数为 2021 年，故低于 2026 年口径下的通行值。
- **健康预留**（M 的 chips）：人均约 20 万，二线 15–30 万，一线 30–60 万，为统计估算区间，非精算值。

## 部署

仓库已含 GitHub Pages 工作流（`.github/workflows/pages.yml`），推送到 `main` 后自动发布到 `https://zdzengzz.github.io/Financial-Freedom-Calculator/`。

工作流首次运行时会自动开启 Pages（`configure-pages` 的 `enablement: true`）。若因权限失败，手动到仓库 **Settings → Pages → Source** 选 **GitHub Actions** 即可。
